Om Nom Run

⭐⭐⭐⭐⭐

About Game

Help Om Nom run through colorful levels and collect delicious treats in this exciting adventure!

Om Nom: Run is a popular 3D endless runner mobile game developed by ZeptoLab in collaboration with Kukouri Mobile Entertainment. It features the iconic green character Om Nom and his friend Om Nelle from the world-famous Cut the Rope universe.

Game Overview

• Genre: Endless Runner / Action

• Platforms: Android, iOS, Web browsers

• Developer: ZeptoLab / Kukouri

• Main Characters: Om Nom, Om Nelle

Key Features & Gameplay

  • Mission-Based Gameplay: Unlike traditional endless runners, the game offers diverse levels with specific goals, such as running a certain distance, performing stunts, or collecting letters to complete words.
  • Power-Ups & Boosters: Players can pick up special items during runs, including Rockets for flying, Magnets to attract coins, and Double Coins multipliers to boost scores.
  • Unlockable Characters & Outfits: Complete tasks to unlock various characters from the Nomville universe along with stylish costumes and skins.
  • Diverse Environments: Run through colorful locations, including bustling city streets, rooftops, underground tunnels, and high-tech robotic factories.
  • Leaderboards & Competitions: Compete against friends and global players to top the leaderboards and earn exclusive rewards.
